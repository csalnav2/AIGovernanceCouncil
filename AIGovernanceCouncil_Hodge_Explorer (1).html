How the browser computes this

The tutorial uses two-pass modified Gram–Schmidt with reorthogonalization to build orthonormal bases of im(B₁ᵀ) and im(B₂). Orthogonal projection gives g and c; h is the residual. No inverse of a singular Laplacian is taken. This is a small educational implementation, not the production sparse solver.

g = Qg Qgᵀ f c = Qc Qcᵀ (f − g) h = f − g − c L₁ = B₁ᵀ B₁ + B₂ B₂ᵀ

Since B₁B₂ = 0, the gradient and curl spaces are orthogonal. A harmonic residual obeys B₁h = 0 and B₂ᵀh = 0. Native application imports retain the backend components; they are not recomputed without the missing triangle incidence matrix.

Read the network, step by step

  1. Orient the edges. i → j is a reference direction. A signed net flow can be positive or negative. A single signed value cannot recover the two gross directions of exchange.
  2. Measure accumulation with B₁. B₁f is net incoming minus outgoing flow at each node. Its sign convention follows the incidence matrix.
  3. Recover a potential difference. g = B₁ᵀφ is the part explained by node potentials. It has no circulation around any closed cycle.
  4. Separate local circulation. c = B₂ψ runs around filled triangular faces. Triangle boundaries can be combined to form larger curl patterns.
  5. Keep the topological remainder. h is divergence-free and orthogonal to all filled-face boundaries. A loop can become curl rather than harmonic when its interior is filled.
f = gradient + curl + harmonic ∥f∥² = ∥g∥² + ∥c∥² + ∥h∥²

A harmonic loop is a spatial property of this chosen complex. It does not, by itself, establish temporal periodicity, stable culture, emergent belief, or political effectiveness. Those interpretations need time series, explicit operational definitions and validation.

Exact three-node example

Choose “Exact check · three-node cycle.” Edge order is AB, AC, BC. The input f = (3, −2, 1) decomposes into g = (1, 0, −1) plus circulation (2, −2, 2). With ABC filled, that circulation is curl; without the face it is harmonic. The squared-norm fractions are 1/7 and 6/7.

Import, export and source provenance

Import either an AIGovernanceCouncil v8.87 “Download JSON” Hodge snapshot with status “ready,” or the explicit explorer format exported by this page. Native graph.total / gradient / curl / harmonic are read as recorded component arrays. Native exports omit triangle identities, so this page cannot independently reconstruct B₂ or certify its curl/harmonic condition. The UI labels those checks unavailable.

Native limits: 300 nodes, 44,850 edges, 16 MB file. Explicit tutorial limits: 80 nodes, 400 edges, 500 triangles. Files are parsed locally. No network request, API key or account is involved. Labels from imports are displayed as text. Imported content is not authenticated as an original simulation export.
